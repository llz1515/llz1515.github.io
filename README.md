# Lizhou Liang · 梁立州

Academic homepage: **https://llz1515.github.io/**

A static, responsive website with research interests, publications, education, honors, and experience.

## Update

Edit `index.html` for content, `styles.css` for appearance, and `script.js` for navigation. Commit and push to `main`; GitHub Pages publishes the repository root automatically. No dependencies or build step are required. `.nojekyll` serves the files directly.

## Assets

The portrait is supplied by Lizhou Liang. University logos identify academic affiliations: [Zhejiang University](https://www.zju.edu.cn/) and [South China University of Technology](https://www.scut.edu.cn/new/9017/list.htm). The layout is inspired by [Naibo Wang’s homepage](https://naibo.wang/).
